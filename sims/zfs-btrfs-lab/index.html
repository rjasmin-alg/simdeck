Btrfs teaching presets

Btrfs 1 · Add block devices

Btrfs is both filesystem and volume manager. It applies data and metadata profiles inside one filesystem, not separate ZFS-style vdevs.

Btrfs 2 · Make filesystem

Btrfs 3 · Subvolumes / snapshots
