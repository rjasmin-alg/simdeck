Core teaching idea: iSCSI, FC, and NVMe/TCP are transport layers. The kernel and device-mapper turn remote storage into block devices; Stratis then manages pools, thinly provisioned XFS filesystems, snapshots, encryption, and caching above those devices.

Connectivity lesson

🌐
iSCSI

TCP/IP network → NIC → iSCSI session → SCSI LUN → block device.

🟣
Fibre Channel

FC fabric → HBA → SCSI LUN → block device. Zoning and LUN masking are outside Stratis.

⚡
NVMe/TCP

TCP/IP network → NIC → NVMe controller connection → namespace block device.

🔀
DM Multipath

Multiple host-visible paths are collapsed into one block device before Stratis consumes it.

⛔
NFS / SMB are different

They expose remote filesystems, not raw block devices, so they do not become Stratis pool members.
